# 轻量音乐服务器

一个放在菜单栏里的小程序：把电脑上的一个音乐文件夹，按“家庭音乐服务器协议”（见仓库根目录的 `docs/protocol.md`）提供给播放器。不需要设置，双击就能用。

## 怎么用

1. 把“轻量音乐服务器.app”放进“应用程序”文件夹，双击打开。菜单栏右上角出现一个小房子加音符的图标。
2. 点开菜单：
   - 第一行是状态：“运行中，共 N 首歌”，或者“启动失败：原因”（例如端口被占用，下面会多一项“重试启动”）；
   - “地址：…　端口：7710”：在播放器里添加服务器时照着填，点按这一行可以拷贝地址；
   - “账号：demo　密码：…”：第一次启动时随机生成，点按这一行可以拷贝密码；
   - “打开音乐文件夹”：在访达里打开 `~/Music/轻量音乐服务器`，把音频文件（FLAC、ALAC/AAC 的 m4a、MP3、WAV、AIFF）拷进去，几秒后服务器就认出来了，播放器刷新即可看到；同名的 .lrc 文件会作为歌词；专辑文件夹里的 cover.jpg（或文件内嵌的封面）会作为封面；
   - “开机自动启动”：打勾后登录系统时自动运行（应用要在“应用程序”文件夹里）；
   - “放入示例音乐”：把自带的 3 张原创示例专辑放进音乐文件夹（已经放过就变灰）；
   - “退出”。

数据位置：账号与设备密钥在 `~/Library/Application Support/轻量音乐服务器/`（只有本人可读），日志在 `~/Library/Logs/轻量音乐服务器/`（不记录密码与密钥）。

## 提供哪些功能

只有一个来源“本地音乐”（来源编号 1）：浏览专辑、歌曲、歌手，按歌曲、专辑、歌手搜索，歌词，封面，播放（支持按字节范围读取）。
软件收藏、歌单、下载、平台账户等写入功能不提供，接口会回 501 和一句说明；DSD、APE、光盘镜像只列出、不能播放。

## 编译

需要 Xcode 与 XcodeGen；依赖仓库根目录的共享组件（MIT，`Package.swift` 里以 `..` 引用）。不使用第三方库。

```sh
swift test                      # 服务器核心的测试
scripts/编译安装.sh              # 编译 Release 版（本机自签名、开强化运行时），装到 /Applications
scripts/编译安装.sh --no-install # 只编译
scripts/生成示例音乐.sh          # 重新生成示例音乐
swift run lms-check 127.0.0.1 7710 demo <密码>   # 连接测试：登录、列专辑、取封面、完整读一首歌
```

调试时可以用环境变量 `LIGHT_MUSIC_HOME`（数据、日志、音乐都放到这个文件夹下）和 `LIGHT_MUSIC_PORT`（换端口）。
